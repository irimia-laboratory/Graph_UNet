This repository contains all of the code used for the manuscript Graph Neural Network Reveals the Cortical Morphology of Local Brain Aging in Normal Cognition and Alzheimer’s Disease". ./visualization_code contains scripts based on Nahian's MATLAB visualization code. I modified them to take inputs more in line with what I need for my project, and to use the colorbar that I like. graph_unet/visualization_code/generate_brain.m is the main script that I call when creating visualizations. ./pooling contains the indices used when downsampling or upsampling across ico levels. These are computed using the surface-projected atlas meshes (i.e. Euclidean space). The script for generating these is ./individual_scripts/get_pooling. ./notebooks contains the Jupyter notebooks used to generate most of my results. Each of these notebooks has its own config namespace, defined in ./config.py. This config file defines important globally preserved variables, like how many vertices are in the starting ico level, and propogates those to the notebook-level configs to ensure consistency across processing. It also defines some small functions for plotting figures or cleaning dataframes since I use these often, but it was annoying to place such small functions in their own file. ./model_outputs gives the outputs of the model and notebooks, including local brain age gaps, visualizations, etc., seperated by cohort and cohort comparison. The organizational logic of it is fairly self-explanatory so that it is easy to find whatever files you need. It does not have raw or processed data, however, which is available at /mnt/md0/projects/graph_unet/atlas_projected_surfaces/ . ./individual_scripts contains some of the one-off scripts that I used for specific tasks when running this code in Jupyter was too inefficient or prone to crashing. This includes training, running ablation, etc. All scripts are named and I ran them simply with python [script name]. These scripts also reference the namespaces from ./config.py , and within the notebooks I mention when I use some file. For instance in the ablation notebook I say to use get_ablation.py . Correspondingly, ablation.py draws from that notebook's namespace for consistency. ./figures contains all of the fully prepped manuscript figures. Some of these are just copies from other files in model_outputs. They are created in one of the notebooks with the exception of Figure_1 which I made in powerpoint and copied over. ./env_gnn is the enviorment that I used for running all code. To give context, I don't have any python 3.10 information on my local. I intentionally removed everything from my user so that I could have more flexibility and control over the modules here. That enviorment has a lot of pip-based installations, which I prefer because pytorch geometric is so finickey. If you run into issues with it, most likely you have local pip installations which are interfering with your packages. ./base_env_pip.txt and ./base_env_conda.yml support recreating this enviorment. They don't have everything, but they do have the pytorch geometric and related versions, which are very difficult to get correct. The CUDA version of the server at the time I used them was 12.6. The Ubuntu version was 22.04. ./GNN_regionalAGs.csv is a one-off file that I made by getting regional averages for my GNN outputs so that I could compare with Nikhil's file that he provided. His predictions are in ./ADNI_Complete_regionalAGs.csv . These are used to compare the models with subject-matched predictions.
